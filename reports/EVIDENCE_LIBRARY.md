# AOMS Evidence Library

## v1 Evidence Corpus
The repository contains 100 generated evidence artifacts under `reports/json/`, corresponding one-to-one with AOMS-001 through AOMS-100.

## Evidentiary Scope
The v1 library demonstrates deterministic rejection when modeled execution conditions differ materially from authorized conditions. Balanced performance, four-decision behavior, six-engine enforcement, transitive provenance, and injected-failure resistance remain Phase II questions.
