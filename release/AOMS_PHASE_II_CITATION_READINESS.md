# AOMS Phase II Citation Readiness

## Repository citation surface

`CITATION.cff` remains the canonical machine-readable citation file. Before final release, confirm author identity, ORCID, title, repository URL, license, candidate-to-final version change, release date, and the archival identifier assigned to the final deposit.

## DOI boundary

Batch 10 does not invent, reserve, or publish a DOI. DOI metadata must be inserted only after an archival service returns an authoritative identifier for the final release record.

## Version boundary

The repository currently declares `2.0.0-rc.1`. The final release process must replace candidate metadata consistently across VERSION, citation metadata, release notes, tag, archive name, and archival deposit.
