# AOMS Phase II 2.0.0-rc.1 Release Notes

## Candidate scope

This candidate advances AOMS from the preserved v1 binary reference runtime to a canonical reconstruction-governed execution system with four terminal decisions: ALLOW, DENY, ESCALATE, and REAUTHORIZE.

## Included evidence

- 100 preserved v1 adversarial cases.
- 250 canonical Phase II cases.
- 60 executable cases across AI agents, finance, healthcare, robotics, civic systems, and emergency response.
- 410 total cases.
- 20 publication claims closed to executable proof.
- Canonical runtime, conformance profile, proof obligations, crosswalks, registries, reports, and frozen hashes.

## Publications and specifications

The candidate includes AOMS-002 through AOMS-004 and AOMS-SPEC-001 through AOMS-SPEC-004, with publication evidence appendices and a claim-to-proof closure matrix.

## Candidate boundary

This is a release candidate only. It is not a certification, peer-review decision, standards adoption, legal determination, professional authorization, or production-deployment approval.
