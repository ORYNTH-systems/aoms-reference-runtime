# AOMS Roadmap

## Preserved Baseline

The 100-case v1 corpus and its generated evidence artifacts remain preserved as the first deterministic demonstration of the authorization non-implication principle.

## Phase II Build Sequence

### Batch 01 - Canonical Foundation
- Public repository front door
- Baseline inventory
- Canonical registries
- Paper-runtime crosswalk
- Public/private boundary
- Phase II architecture manifest

### Batch 02 - Canonical Runtime
- Canonical state objects
- Six ordered governance engines
- GovernanceState and ExecutionContext
- Four-decision semantics
- Provenance chain
- Backward-compatible v1 adapter
- Command-line interface

### Batch 03 - Verification Corpus
- ALLOW, DENY, ESCALATE, and REAUTHORIZE controls
- Failure-injection, multi-agent, delegation, and cross-boundary cases
- Conformance and determinism tests
- Benchmark reports

### Batch 04 - Specifications and Manuals
- Canonical object, engine, boundary, and failure specifications
- Conformance framework and proof documents
- Implementer, operator, auditor, and incident manuals

### Batch 05 - Publications and Release
- AOMS Extension I
- Mathematical foundations
- Verification framework
- Multi-agent, boundary-intelligence, and execution-governance-stack papers
- Reproducible release package
