# AOMS Canonical Registries

These 21 registries control AOMS terminology, objects, state dimensions, engines, invariants, transitions, decisions, violations, boundaries, evidence, authority, delegation, failures, proof obligations, embodiments, conformance requirements, publications, specifications, traceability, extensions, and current-event reconstruction.

Status terms distinguish published canon, existing implementation, planned work, open proof obligations, and controlled material.

Controlled material is not authorized for automatic publication merely because it appears in an architectural registry.
