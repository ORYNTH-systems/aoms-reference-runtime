# AOMS-RG-012 Delegation Registry

| ID | Element | Requirement |
| --- | --- | --- |
| AOMS-DEL-001 | Delegator identity | Must remain reconstructable |
| AOMS-DEL-002 | Delegate identity | Must match the executing principal |
| AOMS-DEL-003 | Delegated scope | Cannot exceed delegator authority |
| AOMS-DEL-004 | Delegation chain | Every link requires current validity |
| AOMS-DEL-005 | Delegation expiry | Must be evaluated at effectuation |
| AOMS-DEL-006 | Delegation revocation | Defeats inherited execution |
| AOMS-DEL-007 | Subdelegation | Requires explicit admissible authority |
| AOMS-DEL-008 | Cross-agent delegation | Does not transfer terminal permission |
