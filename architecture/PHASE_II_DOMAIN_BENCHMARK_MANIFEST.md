# AOMS Phase II Domain Benchmark Manifest

## Wave

Batch 06 establishes six application profiles and a 60-scenario benchmark design mapped to canonical AOMS decisions and proof obligations.

## Domains

AI agents, financial infrastructure, healthcare, robotics, civic systems, and emergency response.

## Admission requirements

- Exactly six profiles and ten scenarios per profile.
- Exactly 60 unique scenario identities.
- Exactly 15 scenarios for each terminal decision.
- Every scenario names an engine focus and proof obligation.
- Every registry and crosswalk reference resolves.
- Existing runtime, corpus, and conformance tests remain green.
- A machine-readable validation report records the result.

## Interpretation

The benchmark matrix is a domain-neutral reference design. `DESIGN-VALIDATED` establishes structural coverage only. Execution proof, external certification, and domain-law validation are separate release states.
