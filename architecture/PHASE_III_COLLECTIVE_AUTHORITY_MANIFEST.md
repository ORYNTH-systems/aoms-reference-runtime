# AOMS Phase III Collective Authority Manifest

Batch 12 establishes the lawful collective-authority substrate required before swarm governance.

## Canonical additions

- `CollectiveExecutionRequest`
- `CollectiveParticipant`
- `DelegationLink`
- `ParticipantEvaluation`
- `CollectiveDecision`
- delegation-chain, scope-composition, quorum, separation-of-duties, collective-admissibility, and accountability engines
- twelve executable collective cases
- normative specification, registries, crosswalk, validation report, and regression tests

## Preserved boundary

The Phase II six-stage runtime remains unchanged. Each participant is evaluated through `CanonicalPipeline`; the collective layer composes those independently reconstructed outcomes and cannot bypass or replace them.

## Foundational separations

- multiplicity is not authority;
- quorum is not authority;
- coordination is not scope;
- delegation is not permission inheritance;
- distribution is not loss of accountability;
- collective capability is not collective admissibility.
